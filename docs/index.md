## What is included

<div class="grid cards" markdown>

-   **Getting Started**

    ---

    Best entry point for developers. Covers integration options, authentication, and the recommended rollout path.

-   **GPA Report Integration Guide**

    ---

    Covers Single API, Bulk API, batch status checks, SFTP uploads, and example request formats. For what happens after a bulk upload and how to troubleshoot it, see [Bulk Import](developer/bulk-import.md).

-   **Webhooks**

    ---

    Covers webhook event references, PDF delivery behavior, and destination-specific setup guidance.

-   **Integrations**

    ---

    Implementation guides for connected systems such as Slate, with setup steps and configuration flow documentation.

-   **Single Sign-On (SSO)**

    ---

    Connect your identity provider — Microsoft Entra ID, Google Workspace, Okta, or any OIDC / SAML 2.0 provider — so your users sign in to Scholaro with their existing work credentials.

</div>
