# Scholaro Developer Documentation

Source for the Scholaro developer documentation published at [docs.scholaro.com](https://docs.scholaro.com).

## Editing docs

All documentation lives in the `docs` folder and is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

To preview locally:

```bash
pip install -r requirements.txt
python -m mkdocs serve
```

## Publishing

Changes merged to `main` are published automatically.
